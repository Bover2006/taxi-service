# BananaTaxi Web App 🚖🍌

**BananaTaxi** — це фронтенд-частина веб-сервісу для замовлення таксі. Проєкт створено як практичну студентську роботу з фокусом на нестандартний UI/UX та реалізацію клієнтської логіки без використання бекенду.

---

## 📌 Про проєкт
Мета цього застосунку — надати користувачам швидкий, інтуїтивний та візуально приємний досвід вибору авто. Дизайн побудований на контрастній жовто-зеленій схемі з гейміфікованими візуальними елементами. Уся бізнес-логіка імітується на стороні клієнта.

## 📋 Реалізовані фічі (Features)
- **Головний екран (Hero):** Інтерактивний лендінг із закликом до дії та яскравою графікою.
- **Модуль автентифікації:** Зверстані та підключені до JS форми входу (Login) і реєстрації (Sign Up).
- **Клієнтська маршрутизація:** Навігація між секціями "Головна", "Замовити" та "Переваги" в межах однієї сторінки.
- **Обробка подій:** Симуляція процесу замовлення через модальні вікна за допомогою чистого JavaScript.

## 💻 Інструкція з розгортання
Проєкт працює автономно і не вимагає встановлення Node.js або налаштування локального сервера.
